I'm currently shaping my M.Sc. thesis proposal around the use of Large Language Models in Software Engineering.

At this stage, I'm especially interested in LLM-assisted code review, software quality, and how these tools can support practical development workflows.

My current goal is to narrow the topic into a clear research problem and define questions that can be evaluated experimentally.

## Current questions

- How can LLMs assist developers during code review?
- What kinds of software quality issues can they reliably identify?
- How should their performance be evaluated beyond simple accuracy?
- Where do current LLM-based approaches fail or become unreliable?

## Next steps

I plan to review recent research on LLM-assisted code review and related software engineering tasks, compare existing approaches, and use those findings to refine the scope of my thesis proposal.

This log will document that process as it develops.
